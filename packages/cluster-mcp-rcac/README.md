# cluster-mcp-rcac

The Purdue RCAC member of the cluster-mcp workspace: the tools that wrap RCAC's own commands
(`myquota`, `storage_paths`, `jobinfo`, `jobcmd`, `jobenv`, `jobscript`, `showpartitions`,
`average_wait`, `slist`, `sfeatures`), importable as `cluster_mcp.rcac`. It is installed as the
`cluster-mcp[rcac]` extra, with `[slurm]` (`cluster-mcp[slurm,rcac]`), not on its own.

Documentation: [docs/rcac/README.md](https://github.com/PurdueRCAC/cluster-mcp/blob/main/docs/rcac/README.md), with its tools, what it needs on the cluster, and how it behaves.
