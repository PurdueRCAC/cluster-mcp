# cluster-mcp-rcac

The Purdue RCAC member of the cluster-mcp workspace: the tools that wrap RCAC's own commands
(`myquota`, `storage_paths`, `jobinfo`, `jobcmd`, `jobenv`, `jobscript`, `showpartitions`,
`average_wait`, `slist`, `sfeatures`), importable as `cluster_mcp.rcac`. It is installed with
`cluster-mcp`, not on its own.

The full documentation is the repository's README: https://github.com/PurdueRCAC/cluster-mcp
