# cluster-mcp-slurm

The Slurm member of the cluster-mcp workspace: the Slurm job and cluster-status tools (`sbatch`,
`squeue`, `scancel`, `sacct`, `sinfo`, `scontrol_show_job`, `scontrol_show_node`), importable as
`cluster_mcp.slurm`. It is installed with `cluster-mcp`, not on its own.

The full documentation is the repository's README: https://github.com/PurdueRCAC/cluster-mcp
