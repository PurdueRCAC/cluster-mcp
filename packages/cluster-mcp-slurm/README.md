# cluster-mcp-slurm

The Slurm member of the cluster-mcp workspace: the Slurm job and cluster-status tools (`sbatch`,
`squeue`, `scancel`, `sacct`, `sinfo`, `scontrol_show_job`, `scontrol_show_node`), importable as
`cluster_mcp.slurm`. It is installed as the `cluster-mcp[slurm]` extra, not on its own.

Documentation: [docs/slurm/README.md](https://github.com/PurdueRCAC/cluster-mcp/blob/main/docs/slurm/README.md), with its tools, what it needs on the cluster, and how it behaves.
